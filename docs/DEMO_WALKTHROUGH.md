# Demo walkthrough (3-5 minutes)

Open https://wastewise-food-waste-intelligence-qeykaa8immms9xxex9aoin.streamlit.app/ (wake/reboot the app first if asleep). Everything shown is SYNTHETIC DEMO DATA.

1. **Landing (0:00)** - note the storage notice and the red *SYNTHETIC DEMO DATA* banner. The demo set auto-loads on a fresh start.
2. **Dashboard (0:30)** - read totals, kg/meal (with its denominator and unmatched-kg note) and the INR metric (assumed prices). Set *Meal* = Dinner; the charts update.
3. **Log waste (1:30)** - open *Log waste*, enter date, session, meal, item, stage, category, kg, method, provenance = measured, and save. Optionally add a meals-served count.
4. **Recommendations (2:15)** - open the tab; expand R8-OVERPROD (Dinner rice), R9-DISLIKED (Lauki sabzi), R10-SPOILAGE and read each rule's evidence.
5. **Interventions (3:00)** - open the dinner-rice batch-cooking intervention; compare baseline and follow-up kg/meal.
6. **Data & export (3:45)** - download the waste-log CSV; mention the *Load / reload synthetic demo data* button and that storage is not durable.
